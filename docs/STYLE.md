# Стиль кода NullServers

Правила одни для всех файлов. Форматирование проверено так: сборка с `-p:DebugType=none` до и после прогона даёт побайтово одинаковую DLL.

## Раскладка

- Фигурные скобки на отдельных строках (Allman).
- Скобка `(` никогда не стоит одна на строке. Условие начинается на строке с `if`/`while`/`foreach`, продолжения переносятся с отступом +4, `)` пишется в конце последней строки условия.
- Вызов с длинными аргументами: `Method(` на строке с именем, аргументы ниже с отступом +4, `);` после последнего аргумента.
- Если выражение помещается в 130 символов, оно пишется в одну строку.
- Цепочки тернарных операторов (`a ? x : b ? y : z`) заменяются на `switch`-выражения.

## Фигурные скобки у тел

- Охранное условие с переходом пишется в одну строку без скобок: `if (!ready) return;` (также `continue`, `break`, `throw`).
- Любое другое тело `if`/`else`/`for`/`foreach`/`while` всегда в фигурных скобках, даже если в нём одна строка.

## Пустые строки

- Ровно одна пустая строка между членами класса.
- Нет пустых строк сразу после `{` и перед `}`.
- Пустая строка ставится после закрывающей `}` блока, если за ней идёт следующий оператор (кроме `else`, `catch`, `finally`, хвоста `do … while (…);`).
- Пустая строка ставится после группы охранных условий.
- Пустая строка ставится перед блоком (`if`/`foreach`/`while`/`try`/…), который идёт после двух и более обычных операторов. Пара «объявили переменную → проверили её» остаётся без разрыва.
- В маленьких блоках (до трёх строк) пустых строк нет: `error = "…"; return false;` пишутся подряд.
- Внутри длинных методов пустая строка отделяет логические шаги: подготовку, работу и результат.

## Имена

- Обфусцированные члены игры (`GJDGDIGECJN` и т.п.) в логике не используются. Для них есть читаемые имена в `Game/GameMembers.cs` (extension-члены C# 14; нужен .NET 10 SDK / VS 2026). Обфусцированные имена остаются только в `nameof(...)` целей Harmony-патчей.
- Каждое имя в фасаде подтверждено по машинному коду игры, см. `docs/GAME_MEMBERS.md`. Члены, смысл которых не подтвердился, не переименовываются.

## Комментарии

- Комментариев в коде нет. Неочевидные знания об игре и FishNet хранятся в `docs/`.

## Инструменты

`research/tools/il2cpp/`:
- `format_style.py`: раскладка и пустые строки.
- `braces.py`: фигурные скобки у тел.
- `strip_comments.py`: удаление комментариев.
- `il2cpp_reader.py` и `disasm.py`: разбор `global-metadata.dat` и дизассемблирование `GameAssembly.dll`.

Запуск: `python research/tools/il2cpp/format_style.py Core.cs Game Additional Customization Network Players Room Sandbox Server UI`.
